# OSAKAAA — 숙소 기준 오사카 맛집 지도

**바로 열기: https://jobless-fish.github.io/OSAKAAA/**

11/13(금)–11/17(화) 오사카 6인 여행용 웹앱입니다. 숙소(大阪市西成区旭2-2-18)를 중심으로,
**예약이 되고 6명이 함께 앉을 수 있는 맛집 83곳**(개별실·단체석·6인 테이블·좌식 확인)과
식당이 아닌 **특이한 장소(볼거리) 21곳 · 라이브 바 4곳 · 주류 상점 11곳 · 면세점 10곳**을 지도와 카드 목록으로 보여 줍니다.
맛집은 숙소를 중심으로 8방위(북·북동·동·남동·남·남서·서·북서)에 고루 퍼지도록 골랐고,
숙소에서 걸어갈 수 있는 곳(직선 1.2km 이내)만 23곳입니다.

## 기능

- **지도 + 카드 목록**: 데스크톱은 왼쪽 목록·오른쪽 지도, 모바일은 전체 화면 지도 + 끌어올리는 바텀시트
- **마커**: 축소하면 가까운 곳끼리 숫자 원으로 묶이고(주황 = 맛집, 보라 = 특이한 장소, 분홍 = 라이브 바, 갈색 = 주류 상점, 청록 = 면세점, 반반 = 섞임), 줌 15부터 하나씩 흰 카드(이름·사진·별점)로 보입니다. 카드끼리 겹치면 점수 높은 곳·특이한 장소를 카드로, 나머지는 점으로 바꿉니다. 숙소는 검은 집 모양 핀
- **특이한 장소**: 보라 테두리 카드 + 아이콘 마커. 왜 재미있는지 한 줄 설명, 시간·요금·휴무, 촬영 에티켓, 공식 안내 링크
- 마커를 누르면 목록의 카드가, 카드를 누르면 지도 위치가 강조됩니다
- **정렬(목록 위 세그먼트 버튼)**: 별점순(기본, 점수 없는 곳·특이한 장소는 맨 뒤) / 거리순(숙소에서 가까운 순) / 음식 카테고리별(장르 제목 아래 별점순, 특이한 장소는 마지막 묶음)
- **빠른 필터 칩**: 도보 5분/10분/15분 이내 · 특이한 장소 · 라이브 바 · 주류 상점 · 면세점만
- **길찾기**: 카드의 '길찾기' 버튼을 누르면 숙소(또는 '내 위치에서 출발' — 브라우저 위치 권한)에서 그곳까지 도보 경로를 지도에 그리고, 라우터가 계산한 거리·시간을 보여 줍니다. 경로는 FOSSGIS의 무료 OSRM 서버(routing.openstreetmap.de, OpenStreetMap 기반)를 버튼을 누를 때만 1번 호출합니다(초당 1회 이하, 같은 경로는 다시 묻지 않음). 실패하면 구글 지도(전철·대중교통) 링크를 쓰세요.
- **면세점 카드**: 2026년 11월 1일부터 바뀐 리펀드 방식(세금 포함 결제 → 출국 때 공항에서 환급, 한 점포 하루 5,000엔 이상, 여권 지참) 안내
- **필터**: 종류(식사/간식/술·바/특이한 장소/라이브 바/주류 상점/면세점), 지역, 장르, 평점, 날짜(그날 영업하는 곳만)
- **여행 중 휴무 표시**: 11/13–17 중 정기휴무일이 있으면 빨간 배지
- 카드마다 타베로그 링크, 코스 링크(있는 곳), 숙소에서 길찾기(구글 지도 대중교통)

## 데이터 (`src/data/restaurants.json`)

- 가게 정보(장르·예산·영업시간·예약·좌석·개별실)는 2026년 11월 9–10일 각 가게 타베로그 페이지에서 확인했습니다.
- **6명 OK 기준**: 예약이 되고, 6명 이상 개별실·6인 테이블·좌식(다다미) 자리·연회 최대 인원(착석) 6명 이상 등 타베로그에 6명이 함께 앉을 수 있다고 적힌 곳만 넣었습니다. 카운터 위주·스탠딩 위주·예약 불가·4인 테이블을 붙여야만 되는 곳은 뺐습니다.
- 타베로그 점수는 가게 페이지에 표시된 값만 넣었고(새로 넣은 53곳은 3.07~3.79), 보이지 않던 곳은 '점수 미확인'으로 둡니다. 숙소 주변 도보권은 3.0 이상, 그 밖은 가능한 한 3.3 이상을 골랐습니다.
- 라이브 바는 공식 사이트·스케줄 블로그로 11/13~17 공연 일정을, 주류 상점은 타베로그·공식 사이트, 면세점은 점포 공식 페이지·관광청 면세점 사이트(TAXFREESHOPS.JP)로 면세 대응을 확인했습니다.
- 특이한 장소는 타베로그·6명 기준과 무관하며, 시간·요금·휴무를 공식 사이트(없으면 오사카시·오사카부 관광 사이트, 위키백과)에서 확인했습니다.
- 좌표: 국토지리원(GSI) 주소 검색으로 번지까지 일치하는 결과를 사용했고(동 단위까지만 맞은 2곳은 타베로그 좌표, 노면전차 정류장·기타카가야역은 OpenStreetMap 좌표), 테스트에서 지역 박스 또는 숙소 반경과 8방위 분포를 검사합니다. 숙소 좌표는 Nominatim 역지오코딩(旭二丁目, 西成区)으로 한 번 더 확인했습니다.
- 거리는 숙소에서의 직선거리이고, 도보 시간은 길이 1.3배 돌아간다고 보고 분속 80m로 계산한 **추정치**입니다.
- 사진은 저장소에 복사하지 않고 타베로그 대표 이미지를 직접 불러오며, 실패하면 자리표시자를 보여 줍니다. 사진·점수의 저작권은 타베로그와 각 게시자에게 있습니다.
- 지도: © [OpenStreetMap](https://www.openstreetmap.org/copyright) 기여자, [Leaflet](https://leafletjs.com/), [Leaflet.markercluster](https://github.com/Leaflet/Leaflet.markercluster).

## UI/UX 가이드

[nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) (★ 약 14.7만, 2026-11-10 기준)을 사용했습니다.
GitHub에서 UI/UX 전용 스킬 중 별이 가장 많은 저장소입니다(범용 스킬 모음 anthropics/skills는 제외).

- `--design-system "restaurant discovery map app"` 결과의 **Minimalism & Swiss** 스타일과 오렌지(브랜드) + 블루(지도·선택) 팔레트를 쓰되, 흰 글자 대비 4.5:1을 넘도록 오렌지를 `#C2410C`로 어둡게 조정
- 우선순위 1–5 규칙 적용: 대비·포커스 링·aria 레이블, 터치 영역 44px 이상(주요 버튼 48px), 이미지 지연 로딩, 모바일 우선, 확대 허용, safe-area 여백
- 드래그 전용 조작 금지 규칙에 따라 바텀시트 손잡이는 탭/키보드(Enter·화살표)로도 단계를 바꿀 수 있음
- UI 아이콘은 SVG, 특이한 장소만 종류를 한눈에 구분하도록 아이콘(이모지) 타일 사용. `prefers-reduced-motion` 존중
- 한글 표시를 위해 웹폰트 대신 시스템 한글 글꼴(Apple SD Gothic Neo / Noto Sans KR 등)을 사용

## 개발

```bash
npm ci
npm run dev      # 로컬 개발 서버
npm run lint     # oxlint
npm test         # vitest (거리 계산·정렬·카드 겹침·데이터 검증)
npm run build    # dist/ 생성 (base: /OSAKAAA/)
```

`main`에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해 GitHub Pages에 배포합니다.
